# Security and privacy policy

Do not report live server addresses, control endpoints, credentials or player data in public issues.

## Private-data reports

If you find personal or private information in this repository:

1. do not quote, copy or screenshot the value in a public issue;
2. report only the affected filename and request private contact with the repository owner;
3. treat IP addresses, UUIDs, player handles, email addresses, chat and machine paths as potentially identifying;
4. request correction or removal if the information relates to you.

## If a secret is committed

1. rotate or revoke it immediately;
2. remove it from current files;
3. treat Git history as compromised;
4. preserve evidence privately before rewriting history;
5. verify dashboard, tunnel and GitHub credentials separately.

This public repository intentionally stores file hashes and reviewed aggregate findings instead of raw logs, generated snapshots, binaries or infrastructure configuration. Automated checks reduce risk but do not replace manual review.
