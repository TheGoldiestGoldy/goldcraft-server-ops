# Repository agent instructions

This is the public community repository. Private operational evidence must remain outside Git.

When updating:

1. generate snapshots and reports only in the private operations workspace;
2. copy only reviewed aggregate conclusions into this repository;
3. distinguish confirmed facts from tentative explanations;
4. never add real names, handles, emails, UUIDs, IP addresses, exact public addresses, machine paths, hostnames, tokens, seeds, raw logs, chat, world data, coordinate datasets, control code, private configuration or third-party binaries;
5. preserve sanitized historical experiment documents;
6. do not change live server files from this repository;
7. prefer one-variable experiments with rollback plans;
8. run the public validation workflow and manually inspect the full diff before publishing.
