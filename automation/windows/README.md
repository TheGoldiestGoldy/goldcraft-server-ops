# Legacy Windows launchers

These files preserve the last Windows launch workflow for comparison and rollback
history. The active server now runs on CachyOS and uses
`../start-server.sh`; do not install these files as the current launcher.

The batch files are useful evidence of the previous Java path, heap policy, port
guard and manual VSS backfill controls. Their presence does not mean their LOD
behavior, Java installation path or limits still match the live Linux server.
